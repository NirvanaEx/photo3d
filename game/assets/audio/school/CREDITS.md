# Recorded sound sources for the expanded classroom

- Walking wood/tile/grass: existing photo3d `steps/` recordings,
  [Footsteps on different surfaces](https://opengameart.org/content/footsteps-on-different-surfaces),
  assembled by **congusbongus**. **swuing**, and **ceberation** for tile; CC BY 3.0.
  Original authors and links are retained in `../CREDITS.md` and source `license.txt` files.
- Running wood/tile/grass variants: **Kenney**, [Impact Sounds](https://kenney.nl/assets/impact-sounds), CC0.
- Gravel walk/run: **Ali_6868**, Gravel Footsteps, existing photo3d recordings, CC0.
- Door opening, closing and latch: **Iwan Gabovitch / qubodup**,
  [Door open, door close](https://opengameart.org/content/door-open-door-close), CC0.
- Garden birds: **isaiah658**, [Ambient Bird Sounds](https://opengameart.org/content/ambient-bird-sounds), CC0.
- Room air: existing synthesized photo3d `room_tone.wav`.

Adaptation: high-pass/low-pass EQ, balanced loudness, short edge fades and loop
crossfade by `scripts/build_school_audio.py`. Run variants use different foley
and a faster gait; they are not claimed to be recordings of continuous running.
CC BY credits must be included with a distributed game.
