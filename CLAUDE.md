# Правила работы над photo3d

Файл читается автоматически в начале каждого сеанса. Здесь не описание проекта
(оно в README), а правила поведения — то, что уже стоило ошибок.

## Проверяй, а не предполагай

**Сверяйся с фактическим API библиотеки до того, как писать под неё код.**
`mcp` встал версии 2.0.0, где `FastMCP` больше нет — вместо него `MCPServer`
с другим декоратором и другим способом возврата картинок. Разведка заняла две
минуты, переписывание сервера заняло бы час.

**Замеряй скорость, а не рассуждай о ней.** «EEVEE растеризатор, значит быстрее
Cycles» — неверно: в WSL EEVEE получает программный GL-контекст и работает
14.3 с/кадр против 1.7 с у Cycles на CUDA. Разница в шесть раз, в обратную сторону
от ожидаемой.

**Смотри на результат глазами, а не только на цифры.** Дважды за сеанс метрики
были идеальными при негодном результате: меш с «4842 гранями, все квады,
замкнутая оболочка» оказался сердцем, повёрнутым на 90°; палитра с виду
корректными числами давала блёклый лосось вместо терракоты. Ни то, ни другое
из отчёта не следовало.

## Не верь коду возврата

**Операторы Blender возвращают `FINISHED`, даже когда ничего не сделали.**
QuadriFlow пишет причину в warning и молча отказывается. Проверять результат
надо по изменению счётчика граней. Это касается любого оператора `bpy.ops`.

**Плагины могут не загрузиться молча.** У pymeshlab без `libopengl0` не
поднимаются Qt-плагины: `import` проходит, а половина фильтров просто
отсутствует. Перед использованием фильтра проверяй `hasattr`, а расхождение
показывай вслух, а не проглатывай.

## Ошибка должна вести к действию

Ошибки этого проекта несут три части: этап, причина и **что конкретно делать**
(`server/errors.py`). Не добавляй ошибок без третьей части — traceback
заставляет гадать, подсказка превращает сбой в следующий шаг.

Если что-то отвалилось молча, скажи об этом в интерфейсе. Пустой вьюер без
объяснения уводит диагностику не туда.

## Инструменты рассчитаны на агента, а не на GUI

- один вызов — законченный результат, без цепочек ради обычного сценария;
- картинки возвращаются в контекст: без них оценивать нечем;
- вызов блокирующий, без очередей и опроса статуса;
- пути принимаются в любом виде, включая `D:\папка\файл.jpg`;
- `model_id` по умолчанию `last`.

## Что писать в README

Каждую грабку — с симптомом, причиной и лечением, в `docs/PITFALLS.md`.
Каждое неочевидное решение — с обоснованием прямо в коде, рядом с местом.
Комментарий «почему так» важнее комментария «что делает».

## Железо

RTX 3060 12 ГБ, 16 ГБ ОЗУ — узкое место именно ОЗУ, WSL ограничена 10 ГБ.
GPU занят Windows на ~1.5 ГБ, реально доступно около 10.7 ГБ.
Тяжёлые модели считать в разрешении, которое туда влезает, а не «как обычно».
